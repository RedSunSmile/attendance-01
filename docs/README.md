## 출석관리 기능
- [ ] 메뉴 선택 
ex) 시작할 때  오늘은 12월 13일 금요일입니다.
ex) 출력(DateTimes.now()), 1~4, Q입력
- [x] 교육 시작 시각
ex) 월 13:00, 화~금 10:00 (5분 초과 지각,30분 초과 결석)
- [ ] 출석 확인
ex) 닉네임, 등교 시간 입력
ex) 12월 13일 금요일 09:59 (출석) 출력
- [ ] 이미 출석 했으면 다시 출석 못 함
- [ ] 크루별 기록
ex)전날까지 기록, 출석,지각,결석 횟수 세기, 경고,면담,제적,판정 출력
- [ ] 출석 수정
ex) 닉네임, 날짜(일), 바꿀 시간 입력
ex) 10:07 (지각)
-> 해당 요일의 시작시간부터 5분 초과 지각
-> 해당 요일의 시작시간부터 30분 초과 결석
-> 등교하지 않아 출석 기록 없는 날 결석
- [ ] 제적 위험자 정렬
ex) 제적->면담->경고 순, 같은 등급 안에서는 지각을 결석으로 바꿔서 많은 순,같으면 닉네임 가나다 순
- [ ] 지각 3회 결석 1회로 간주
ex) 경고 대상자: 결석 2회 이상
ex) 면담 대상자: 결석 3회 이상
ex) 제적 대상자: 결석 5회 초과
- [ ] 캠퍼스 운영 시간 매일 8:00-23:00시
- [ ] 주말 및 공휴일 출석 받지 않음
ex) 12월 공휴일:25일 (요구사항 달력 이미지 기준)
- [x] 출석 시스템 등록된 크루와 12월 출석 기록은 제공된 파일
ex) attendances.csv로 확인
- [ ] 프로그램 사용자가 종료할 때까지 종료되지 않는다
- [ ] 해당 기능을 수행한 후 초기화면으로 돌아간다
- [ ] 예외처리 [ERROR]로 시작 IllegalArgumentException발생
- [ ] 닉네임 입력하기
ex) 닉네임을 입력해 주세요.
- [ ] 등교시간 입력하기
ex) 09:58
- [ ] 출력하기
ex) 12월 05일 화요일 09:59 (출석)
- [ ] 출석 수정
ex) 출석을 수정하려는 크루의 닉네임을 입력해 주세요.
ex) 수정하려는 날짜(일)를 입력해 주세요.
ex) 언제로 변경하겠습니까?
09:58
ex) 12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
- [ ] 크루별 출석 기록 확인하기
ex) 이번 달 빙티의 출석 기록입니다.
.......
ex) 면담 대상자입니다.
- [ ] 제적 위험자 확인 만들기
ex) 제적 위험자 조회 결과
-빙티: 결석 3회, 지각 4회 (면담)
- [x] 닉네임과 출석일시 기록 입력 만들기 
ex) nickname,datetime
ex) 쿠키,2024-12-13 10:08
ex) 빙봉,2024-12-13 10:07
- [ ] 기능 선택 항목, 날짜 또는 시간 잘못된 형식 예외처리
ex) [ERROR] 등록되지 않은 닉네임입니다.
ex) [ERROR] 아직 수정할 수 없습니다.
ex) [ERROR] 캠퍼스 운영 시간에만 출석이 가능합니다.
ex) [ERROR] 이미 출석을 확인하였습니다. 필요한 경우 수정 기능을 이용해 주세요.
ex) [ERROR] 잘못된 형식을 입력하였습니다.
ex) [ERROR] 12월 14일 토요일은 등교일이 아닙니다.
ex) 에러가 나면 프로그램 종료(다시 입력받지 않음)
- [ ] 실행 결과 예시 출력
